# Hephia Event Sandbox

Practice `/start-event` and every signup button here, without touching Discord. Everything stays in your browser. **↺ Reset** starts over.

- Type `/` in the chat bar to run `/start-event`. Your announcement is already posted in 🎭｜events.
- Click a member at the bottom to see their roles, change them, or **act as** them (sign up, vote, add a +1…).
- Use **🕒** in the top bar to skip ahead (Starting Soon, event start, event end).
